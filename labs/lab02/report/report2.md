## 2. Теоретическая часть

В Linux информация о пользователях хранится в файлах:
- `/etc/passwd` — основная информация о пользователях (имя, UID, GID, домашний каталог, оболочка);
- `/etc/shadow` — хешированные пароли и параметры их старения;
- `/etc/group` — информация о группах и их участниках.

Права доступа определяются тремя категориями: владелец, группа, остальные.  
Суперпользователь (root) имеет UID 0 и полный доступ к системе.

### 3.2. Работа с sudo

- Открыт файл `/etc/sudoers` через `sudo visudo`.
- Найдена строка `%sudo ALL=(ALL:ALL) ALL`, которая даёт членам группы sudo право на выполнение любых команд.

### 3.3. Создание пользователей

- Создан пользователь `alice` командой `sudo useradd -m -G sudo alice` и задан пароль через `sudo passwd alice`.

- Создан пользователь `carol` командой `sudo useradd -m carol` и задан пароль.
- Проверено, что у новых пользователей созданы домашние каталоги и скопированы файлы из `/etc/skel`.

## 5. Ответы на контрольные вопросы

1. Команды `id`, `groups`, `id -nG` позволяют узнать UID, GID и группы пользователя.

2. UID пользователя root — 0. Узнать UID можно командой `id -u` или `grep root /etc/passwd`.

3. `su` — полное переключение на другого пользователя (требует пароль целевого пользователя). `sudo` — временное выполнение команды от имени root (требует пароль текущего пользователя).

4. Параметры sudo настраиваются в файле `/etc/sudoers`.

5. Для безопасного изменения `/etc/sudoers` используется команда `visudo`.

6. Чтобы пользователь мог выполнять команды через sudo без пароля, его нужно добавить в группу `sudo` (в Ubuntu) или `wheel` (в Rocky Linux).

7. Параметры создания учётных записей задаются в файлах `/etc/login.defs` и `/etc/default/useradd`.

8. Информация о первичной и дополнительных группах хранится в `/etc/passwd` (GID) и `/etc/group` (список участников).

9. Для изменения параметров пароля используется команда `passwd` с ключами `-n`, `-w`, `-x` (например, `passwd -n 30 -w 3 -x 90 user`).

10. Для прямого изменения `/etc/group` используется команда `vigr` (аналог `visudo` для групп), потому что она проверяет синтаксис файла перед сохранением.
