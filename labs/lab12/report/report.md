# Лабораторная работа №12

## Цель работы
Изучить основы программирования в оболочке ОС UNIX. Научиться писать более сложные командные файлы с использованием логических управляющих конструкций и циклов.

## Выполнение работы

### Задание 1. Механизм семафоров
Создан скрипт `semaphore.sh`, реализующий упрощённый механизм семафоров.

### Задание 2. Реализация команды man
Создан скрипт `myman.sh`, который выводит справку по команде из `/usr/share/man/man1/`.

### Задание 3. Генерация случайных букв
Создан скрипт `random_letters.sh`, генерирующий случайную последовательность букв латинского алфавита.

## Выводы
Освоены сложные конструкции bash: семафоры, работа с man, генерация случайных последовательностей.
